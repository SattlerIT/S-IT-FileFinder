v1.2.16  |  Changelog

All notable changes to S-IT FileFinder, newest version at the top.
Versions 1.2.5–1.2.11 were internal interim steps and are summarised in v1.2.12.

v1.2.16 – Four languages: German, English, French, SpanishCURRENT

  • Language selection: The program is now available in four languages. You switch languages in the settings dialog, in the new "Language" section (with flags); after a short confirmation, FileFinder restarts in the language you chose. The setting is stored in FileFinder-config.ini – with no entry there, everything stays in German as before.
  • Fully translated: Interface, context menu, status messages, all message windows, the results manager and the window for file actions (copy, move, recycle bin).
  • Result report in the selected language: The HTML report follows the program language – headings, columns and the details at the top.
  • Help in four languages: The help button opens the help file directly in the language that is set. Every help page carries a language bar at the top for switching between the four versions.

v1.2.15 – Start button, search scope in the report & website link

  • Start button: New 🏠 button in the header bar – returns the program to the empty start view at any time, including from a loaded result or from the large-files view.
  • Search scope in the report: After a folder search, the result report and the results manager now show the folder path that was searched (the entry is called "search scope" instead of "drives"). When a saved folder search is loaded, the folder is put back into the folder field.
  • Website link: New 🌐 link in the footer – opens the FileFinder project page in the browser.
  • Suggestions from users in daily practice, put into effect – thank you!

v1.2.14 – Folder search, faster drive search & 90 % scaling

  • Folder search: The new folder field limits the search to one particular folder and its subfolders instead of whole drives – this applies to the large-files view as well. The drive selection is disabled while a folder is set; clearing the field brings the previous selection back automatically.
  • Faster drive search: The exclusion of the Windows system folders (Windows, $Recycle.Bin, System Volume Information and others) in the root of each drive now works reliably – searches across the system drive are noticeably faster and no longer return hits from those folders.
  • Scaling from 90 %: New 90 % step in the settings dialog for a more compact display on smaller screens.
  • Help revised: New section on the search scope (folder or drives), plus a practical tip on the targeted folder search.
  • The licence and the disclaimer are now included in the package.

v1.2.12 – Sorting, large files, file actions & results manager

  • Sorting: Sort the hits by clicking a column heading (name, size, date, path). Size and date are sorted by their real value, not by the text shown.
  • Large files: Show the 100 largest files on the selected drives at the push of a button – to track down space hogs quickly.
  • File actions: Select several hits and copy them, move them or send them to the recycle bin in a separate window – with a byte-accurate progress bar and without overwriting (automatic renaming if a name already exists).
  • Save results: Save search results, load them again later or view them as an HTML report – all managed in the new results manager.
  • Configuration: Central dialog for display size, extended filters at startup and default sorting (stored in FileFinder-config.ini).
  • Updated help file and numerous improvements in detail.

v1.2.4 – 2026-04-16 – Reliable restart

  • Restart fix: Switching the display size now starts the new instance reliably, without "Failed to import encodings"; the compiled EXE is started directly.
  • --onedir: Switched to a folder-based EXE – nothing is unpacked into Temp at startup.
  • A restart delay of 200 ms prevents a race condition while closing.

v1.2.3 – Layout of the extended filters

  • Clearer labels: "creation date" and "modification date".
  • Consistent icons (📅 📏 ✏️), aligned underneath each other.
  • From/to fields closer together, labels aligned left.

v1.2.1 – Sizes in MB

  • The size filter works in megabytes instead of kilobytes.
  • The maximum size is recognised automatically as MB or GB in the HTML result log.

v1.2.0 – View & extended filters

  • F11 toggle for the date and size filters; the window height adjusts automatically.
  • Display size selectable (100–200 %) with an optional program restart.
  • Full DPI/4K scaling for high-resolution screens.
  • Automatic window width when there are many drive letters.
  • Improved date labels, revised header, automatic size and position at startup.

v1.0.1 – Bugfix: startup behaviour

  • Fixed the freeze at startup on systems with a DVD drive or card reader without a medium inserted (drives are now determined through the Windows API).

v1.0.0 – First release

  • Search by parts of a name, file type, creation/modification date and file size.
  • Multi-drive support with an "all" checkbox.
  • HTML result log with clickable paths.
  • Context menu: open folder, open file, copy path.
  • Help button with HTML documentation.
